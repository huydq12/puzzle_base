### General Information

AppLovin MAX is an ad mediation platform that allows developers to monetize mobile apps by combining multiple ad networks into a single auction. It automatically selects the advertiser offering the highest CPM, thereby increasing revenue and ensuring stable ad delivery.

### 1\. Access and Settings

All keys and identifiers for integration are provided by the Integrations Department (to initiate the process, fill out the Integrations & Release Team [task request form](https://form.asana.com/?k=8hxzseI9fpdNNqVYM0KKGQ&d=713732988947687)):

AppLovin SDK Key

AdMob App ID

Ad Unit IDs (Rewarded, Interstitial, Banner)

> ⚠️ Important: Different AdMob App IDs and Ad Unit IDs are used for Android and iOS.

The Integrations Team also handles connecting ad networks on the AppLovin side.

### 3\. Ad display

Below is an example of loading and displaying an interstitial ad.

AdvertisingService.IntegrationsSettingsContainer.MaxSettings.InterstitialId : string.Empty; public override bool IsInterstitialAvailable { get; protected set; } public override double LoadedRevenue \=> \_loadedAdRevenue; public MaxInterstitialModuleImplementor(IAdvertisingService service) : base(service) { // Attach callback MaxSdkCallbacks.Interstitial.OnAdLoadedEvent += OnInterstitialLoadedEvent; MaxSdkCallbacks.Interstitial.OnAdLoadFailedEvent += OnInterstitialLoadFailedEvent; MaxSdkCallbacks.Interstitial.OnAdDisplayedEvent += OnInterstitialDisplayedEvent; MaxSdkCallbacks.Interstitial.OnAdClickedEvent += OnInterstitialClickedEvent; MaxSdkCallbacks.Interstitial.OnAdHiddenEvent += OnInterstitialHiddenEvent; MaxSdkCallbacks.Interstitial.OnAdDisplayFailedEvent += OnInterstitialAdFailedToDisplayEvent; MaxSdkCallbacks.Interstitial.OnAdRevenuePaidEvent += OnInterstitialRevenuePaidEvent; } public void LoadInterstitial() { IsInterstitialAvailable \= false; requestDate \= DateTime.Now; Debug.Log($"\[MaxInterstitialModuleImplementor - LoadInterstitial\] {InterstitialId}"); LoadInterstitialWithId(); } private void LoadInterstitialWithId() { MaxSdk.LoadInterstitial(InterstitialId); } public override void ShowInterstitial(string placementName) { \_isWatched \= false; Invoke\_OnAdStarted(AdActionResultType.Watched, ShowDelay, string.Empty, placementName, \_adDataDictionary); MaxSdk.ShowInterstitial(InterstitialId, placementName); } private void OnInterstitialLoadedEvent(string adUnitId, MaxSdkBase.AdInfo adInfo) { IsInterstitialAvailable \= true; // Interstitial ad is ready for you to show. MaxSdk.IsInterstitialReady(adUnitId) now returns 'true' responseDate \= DateTime.Now; \_adDataDictionary \= ExtractInfo(adInfo); \_loadedAdRevenue \= adInfo.Revenue; Debug.Log($"\[AppLovinMax\] Interstitial ad loaded successfully. Ad Unit ID: {adUnitId}, Revenue: {\_loadedAdRevenue}"); // Reset retry attempt retryAttempt \= 0; Invoke\_OnAdRespond(ResponseDelay, AdActionResultType.Watched, string.Empty, adUnitId); } private void OnInterstitialLoadFailedEvent(string adUnitId, MaxSdkBase.ErrorInfo errorInfo) { // Interstitial ad failed to load responseDate \= DateTime.Now; retryAttempt++; CallLoadInterstitialWithDelay().Forget(); Invoke\_OnAdRespond(ResponseDelay, AdActionResultType.Error, $"{errorInfo.Message} Info: {errorInfo.AdLoadFailureInfo}", adUnitId); } private async UniTaskVoid CallLoadInterstitialWithDelay() { // AppLovin recommends that you retry with exponentially higher delays, up to a maximum delay (in this case 64 seconds) double retryDelay \= Math.Pow(2, Math.Min(6, retryAttempt)); await UniTask.WaitForSeconds((float)retryDelay); LoadInterstitial(); } private void OnInterstitialDisplayedEvent(string adUnitId, MaxSdkBase.AdInfo adInfo) { Invoke\_OnAdShow(AdActionResultType.Watched, ShowDelay, string.Empty, adUnitId); } private void OnInterstitialAdFailedToDisplayEvent(string adUnitId, MaxSdkBase.ErrorInfo errorInfo, MaxSdkBase.AdInfo adInfo) { // Interstitial ad failed to display. AppLovin recommends that you load the next ad. LoadInterstitial(); Invoke\_OnAdShow(AdActionResultType.Error, ShowDelay, $"{errorInfo.Message} Info: {errorInfo.AdLoadFailureInfo}", adUnitId); } private void OnInterstitialClickedEvent(string adUnitId, MaxSdkBase.AdInfo adInfo) { var data \= ExtractInfo(adInfo); Invoke\_OnAdClick(adUnitId, data); } private void OnInterstitialHiddenEvent(string adUnitId, MaxSdkBase.AdInfo adInfo) { // Interstitial ad is hidden. Pre-load the next ad. LoadInterstitial(); var data \= ExtractInfo(adInfo); Invoke\_OnAdHide(\_isWatched? AdActionResultType.Watched : AdActionResultType.Canceled, string.Empty, adUnitId, data); } private void OnInterstitialRevenuePaidEvent(string adUnitId, MaxSdkBase.AdInfo adInfo) { Debug.Log($"---> Inter1 revenue paid {adInfo.Revenue}"); \_isWatched \= true; Invoke\_OnImpressionDataReceive(MaxUtils.GetRevenueInfo(AdModule, adInfo), adUnitId); } private static Dictionary<string, object\> ExtractInfo(MaxSdkBase.AdInfo adInfo) { var data \= new Dictionary<string, object\> { { "network", adInfo.NetworkName }, { "creo\_id", adInfo.CreativeIdentifier.Replace(",",".") }, { "revenue", Math.Round(adInfo.Revenue, 6).ToString(System.Globalization.CultureInfo.InvariantCulture)} }; return data; } } }

Below is the code you can use to track events

Unity integration

MaxSdk.TrackEvent( <event\-name\>, <event\-data\> );

Before sending the event itself, send a log from Unity (Debug.Log(data)). Applovin logs will not display parameters in events.

Debug.Log( $"\[MaxSdkAnalytics\] - purchase: \\n" + $"Inapp Id: {inappId}, \\n" + $"Currency: {currency}, \\n" + $"Price: {price}, \\n" + $"Inapp Type: {inappType}, \\n" + $"Is Subscribe: {isSubscription}");

### 5\. Retry Logic — logic for reloading ads

#### What is it

Retry Logic is a mechanism that ensures a retry of ad loading if the first attempt fails (for example, due to a lack of internet connection, network failure, or a temporary glitch). It is important to apply this logic only to rewards and interstitials, as the banner itself initiates a reload upon failure. If you manually trigger a reload for a banner, it may result in an ANR or a crash.

#### Why is this necessary

Increases the stability of ad impressions.

Increases revenue by reducing the number of "empty" impressions.

Helps avoid errors in analytics and A/B testing.

#### How to implement

Configure a retry after a failed load by subscribing to the corresponding callback.

Increment the attempt counter for each failed load.

Set retryDelay to increase exponentially, as recommended by Applovin.

When the ad loads, reset the attempt counter to 0

Log all attempts and errors for debugging convenience.

#### Example logic

private void OnInterstitialLoadFailedEvent(string adUnitId, MaxSdkBase.ErrorInfo errorInfo) { // Interstitial ad failed to load \_responseDate \= DateTime.Now; // AppLovin recommends that you retry with exponentially higher delays, up to a maximum delay (in this case 64 seconds) \_retryAttempt++; double retryDelay \= Math.Pow(2, Math.Min(6, \_retryAttempt)); UniTask.Delay(TimeSpan.FromSeconds(retryDelay)).ContinueWith(LoadInterstitial); Invoke\_OnAdRespond(ResponseDelay, AdActionResultType.Error, $"{errorInfo.Message} Info: {errorInfo.AdLoadFailureInfo}", adUnitId); }
