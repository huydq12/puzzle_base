## General Information

#### 1\. Terms & Privacy window (displayed first, for all regions)

Terms & Privacy are documents that establish the rules for using the game, limit the developer’s liability, explain what players can and cannot do, and protect the publisher in the event of disputes, bans, refunds, etc.

Additionally, in many countries, the law explicitly requires notifying users about data collection and processing before they start using the product, for example (GDPR in the EU).

GDPR - General Data Protection Regulation, a law that helps European Union citizens control their own personal data. Personal data on the internet includes any information about an identified natural person (an individual). Or any information relating to an identified natural person, that is, information that can be used to identify a natural person.

#### 2\. CMP Window (displayed second, for the EU, UK, Norway, Liechtenstein, Iceland, Brazil, and Switzerland)

CMP (Consent Management Platform) is a platform that helps users determine what personal data they are willing to share with companies. Providing users with this option is required by GDPR. Advertising and analytics integrations either prohibit their use in apps without a CMP or automatically restrict data collection, which significantly impacts their effectiveness.

Many countries are developing and adopting their own laws similar to the GDPR (e.g., Brazil), so the list of countries where the CMP window appears may change, but this does not require additional integration steps—it is configured remotely. The CMP window is automatically displayed by UCM for users from the EU, UK, and Brazil.

The user can consent to data transfer for all integrations, or configure consent separately for each personal data processor (vendor).

There are far more vendors than might appear at first glance based on the integrations in the project, because a single integration (such as an ad network) may transfer data to third parties. These third parties are also included in the list of vendors in the CMP window.

Important: We cannot influence user responses in the CMP. The decision to send analytics is made behind the scenes by the CMP. It is not possible to make changes to the interface

Example of the CMP window for Android and iOS

#### 3\. ATT window (shown third, only on iOS 14.5+)

ATT (App Tracking Transparency) is a policy and framework introduced by Apple in iOS 14.5 that requires app developers to request permission from users before tracking their activity outside the app. This applies to the collection of IDFA for advertising and analytics purposes.

This window allows the user to choose whether their advertising identifier (IDFA) will be collected. If the user agrees to have their IDFA collected, they may be shown targeted ads, download attribution will be tracked, and other information will be collected to make advertising and traffic buying more effective. If the user opts out of IDFA collection, no data about them will be collected.

Important: If the user has set a default opt-out for all such requests in their system settings, the window will not appear, and integrations will automatically assume that the user has opted out. This is a native iOS window.

## How “consent” works in the module

Window display sequence: Privacy Policy & Terms of Use → CMP → ATT

For Android, the ATT window will not be displayed (not required)

For iOS, the ATT window is displayed automatically for iOS 14.5+

User Consent must be initialized strictly before SDK initialization begins

The CMP window affects data transmission to Firebase + personalized advertising in the EU, UK, and Brazil

💡

If there is no internet connection or the connection is poor, the CMP window may not appear on the first launch. An attempt to display it will be made on the next launch.

### 3\. Usage

After completing the preliminary setup described in the section above, you need to take the following steps in your project’s code:

Do not initialize analytics SDKs, or initialize them with event sending disabled. If you want analytics data before UCM, store it in your own buffer, which can be sent to analytics after passing through UCM.

As soon as possible after the game launches (for example, as the first step of loading), call

UserConsentManager.Instance.StartFlow(Action callback)

💡

If your app works with Google Play Pass and it is active, pass the additional parameter isGpp == true

: UserConsentManager.Instance.StartFlow(Action callback, isGpp:true)

Pause the download or run it in the background, but do not start gameplay

Wait for the

callback

Resume sending events after receiving

the callback

Pass all necessary consents to the SDK in the

callback

body

Continue downloading the game or start gameplay

⚠️

If you are using Firebase, we recommend initializing it alongside UCM, or beforehand.

Example:

UserConsentManager.Instance.StartFlow(() \=> { if (!MaxSdk.HasUserConsent()) { MaxSdk.SetHasUserConsent(true); MaxSdk.SetDoNotSell(false); } // pass consent to any SDKs that require explicit consent // resume sending analytics events AppMetrica.SetDataSendingEnabled(true); // If you are using a buffer for analytics events, you can send them. \_analyticsBuffer.Flush(); // continue loading the game or start the gameplay });

## Usage for non-Unity engines

The UCM package was developed specifically for Unity. However, for games developed on other engines, there is a set of requirements and recommendations on how to create your own equivalent of the User Consent Manager.

The Terms & Privacy window must be created using your game engine, taking into account:

It cannot be skipped except by clicking the “Agree” button

It must contain links to the Terms and Privacy policies, respectively. These must be clearly identifiable by the user as links or clickable buttons.

The text in the window must match the texts [in this table and](https://docs.google.com/spreadsheets/d/1YYFu6YXPh7lUpYZANby425Ie40CipCIbkPnlimXHn_M/edit?gid=645418412#gid=645418412) the localizations listed there.

The game settings must include a "Privacy Settings" button that opens the Terms & Privacy window.

The CMP window must be from Google UMP. It will be configured for you by the integration team (appearance, content, localizations). However, the technical implementation is your responsibility.

The window should appear immediately after Terms & Privacy for the list of countries where this window is required. ## Troubleshooting

Make sure you have performed EDM → Force Resolve.

#### NoClassDefFoundError

If you encounter a crash with the signature: java.lang.NoClassDefFoundError, verify that you are using

androidx.core:core:1.8.0

or higher in

the Gradle launcherTemplate.

If CMP or any other part of the UCM flow is not working correctly, please provide logs tagged with

\[Azur User Consent Manager\]

and the logs from the Development build to the [#package-user-consent-manager](https://azurgames.slack.com/archives/C067CLBR04Q) channel.

If this is iOS, you need logs from the app connected to Xcode.

#### AD\_SERVICES\_CONFIG

If an error similar to the following occurs during the build:

Manifest merger failed : Attribute property#android.adservices.AD\_SERVICES\_CONFIG@resource value\=(@xml/gma\_ad\_services\_config) from \[com.google.android.gms:play\-services\-ads\-lite:23.4.0\] AndroidManifest.xml:109:13\-59 is also present at \[com.google.android.gms:play\-services\-measurement\-api:22.1.2\] AndroidManifest.xml:32:13\-58 value\=(@xml/ga\_ad\_services\_config). Suggestion: add 'tools:replace\="android:resource"' to <property\> element at AndroidManifest.xml to override.

​

To resolve this error in

the

project’s main

AndroidManifest

, you need to:

Add to

the manifest

:

xmlns:tools="http://schemas.android.com/tools"

Add inside

the application

tag:

<property android:name\="android.adservices.AD\_SERVICES\_CONFIG" android:resource\="@xml/gma\_ad\_services\_config" tools:replace\="android:resource" />

## FAQ

Q: Can we use Applovin MAX Flow? A: No.

Q: What should we do if we use Ironsource LevelPlay mediation? A: Follow these instructions

Q: What if a user launches the game without an internet connection? A: The Terms & Privacy window is not internet-dependent and is always displayed, preventing the player from proceeding until they accept it. The CMP will be displayed and accounted for upon the next launch with an internet connection.

Q: Do we need to display the Terms & Privacy window for all countries? A: Yes

Q: Is it possible to decline consent in the Terms & Privacy window and continue playing? A: No. The package does not allow skipping the Terms & Privacy window by minimizing and maximizing the application, or by restarting the game
